# Highlander Robotics website

Planning and future source code for [frc8033.com](https://www.frc8033.com/), the website of FIRST Robotics Competition Team 8033.

## Current status

Documentation only. The current website remains on Webflow. This repository does not deploy a website yet.

The proposed implementation follows the framework used by [Piedmont Makers](https://github.com/piedmontmakers/piedmontmakers.org): Astro 5, Tailwind CSS 4, TypeScript, Markdown content collections, and GitHub Pages.

## Documentation

- [Website feature and integration audit](docs/website-audit.md): 24 discovered public pages, external services, migration requirements, and known verification limits.
- [Website migration plan](docs/migration-plan.md): implementation steps, proposed content structure, editing workflow, and launch checks.
- [Original audit report in Word format](docs/website-audit.docx).

The audit and plan record research from November 5, 2026. Recheck service destinations and framework dependencies before implementation.
